# .github

Organisation-wide defaults for [xfina-dev](https://github.com/xfina-dev).
GitHub uses a file here for any repository that has none of its own.

| File | What it does |
|---|---|
| [`profile/README.md`](profile/README.md) | The page shown at [github.com/xfina-dev](https://github.com/xfina-dev) |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | How to contribute, and the rule against publishing real financial data |
| [`SECURITY.md`](SECURITY.md) | How to report a vulnerability privately |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) | The problem, idea and story forms, copied from [xfina-ui's `issue-templates/`](https://github.com/xfina-dev/xfina-ui/tree/main/issue-templates). The field ids (`tool`, `environment`) are the ones the sites' feedback links fill in |
| [`.github/pull_request_template.md`](.github/pull_request_template.md) | The pull request description, with a data-safety checklist |

A repository with its own `.github/ISSUE_TEMPLATE/` uses only its own forms, not these.

# Xfina

Open-source tools, data and engines for privacy-first personal finance in India.
Everything that touches your own statements runs in your browser: no file is
uploaded to a server.

| | What it is | Where |
|---|---|---|
| [**Xfina**](https://github.com/xfina-dev/xfina) | Reads Indian bank, credit card, mutual fund and brokerage statements into one standard JSON (Sahamati AA / ReBIT), in Rust compiled to WebAssembly. Also on crates.io, npm and PyPI | [xfina.dev](https://xfina.dev) |
| [**Xfingine**](https://github.com/xfina-dev/xfingine) | Pure computation engines for financial planning: data in, arithmetic, data out. Rust core, shipped to crates.io, npm and PyPI | — |
| [**Xfina Data**](https://github.com/xfina-dev/xfina-data) | Open Indian financial datasets (FX and inflation, with more as needed), with every source document kept | [data.xfina.dev](https://data.xfina.dev) |
| [**Xfina Labs**](https://github.com/xfina-dev/xfina-labs) | Experimental apps built on Xfina and Xfingine, starting with the Portfolio Engine | [labs.xfina.dev](https://labs.xfina.dev) |
| [**xfina-ui**](https://github.com/xfina-dev/xfina-ui) | The theme and components every xfina.dev site shares | [npm](https://www.npmjs.com/package/xfina-ui) |

All projects are licensed under Apache-2.0.

Found a problem, or have an idea? Open an issue on the project it belongs to.
Issues are public, so never attach a statement or include names, account
numbers or amounts.

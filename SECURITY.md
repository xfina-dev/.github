# Security policy

Xfina's tools handle people's financial statements, so we take reports seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately through GitHub:
open the repository's **Security** tab and choose **Report a vulnerability**.

Include what you found, the steps to reproduce it, and the version or commit
you tested. Do not include a real statement or anyone's financial details; a
made-up file that shows the problem is enough.

We aim to acknowledge a report within a few days and will keep you updated
until it is fixed. We are happy to credit you in the release notes.

## Supported versions

Fixes go into the latest release of each project. Older releases are not
patched.

## Scope

In scope: anything that could let a statement or the data read from it leave
the user's device, run code from a crafted input file, or tamper with a
published package or dataset.
